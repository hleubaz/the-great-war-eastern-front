# The Great War: The Eastern Front

Play at https://hleubaz.github.io/the-great-war-eastern-front/.

`index.html` and `multiplayer.html` are self-contained game pages: their JavaScript, styles, and embedded fonts are included directly, in the original loading order. No separate game assets are required.

Enable GitHub Pages from the main branch, root folder. Keep both HTML files and `.nojekyll` at the root.

Multiplayer connects to the existing cloud relay at `https://the-great-war-eastern-front.bigboy8.chatgpt.site`. Create a room and share the GitHub Pages invite; keep the host’s game open during the match. No local server or VPN changes are needed.
